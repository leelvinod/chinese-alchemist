# Mandarin Mitra on Replit

Mandarin Mitra is a React + TypeScript mobile web app served by Vite.

## Run

- The `Start application` workflow runs `npm run dev`.
- The development server listens on `0.0.0.0:5000` for Replit Preview.
- Install dependencies from the lockfile before first run.

## Verify

- `npm test` runs the Vitest suite.
- `npm run build` typechecks the project and creates a production build.

The current MVP needs no external secrets or services. Learner progress is stored in the browser's local storage, and speech uses browser APIs when available.
